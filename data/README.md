# Component and interaction data

The provisional [source extract](source-extracts/components.provisional.json) contains eight CAS-matched component constant records from pinned CoolProp 7.2.0 data and gas-phase NASA7 records from pinned Cantera 3.2.0 data. Upstream license notices are retained alongside it.

The Rust engine evaluates the embedded data directly. The [independent validation workflow](../validation/clapeyron-checks.md) uses Clapeyron.jl to generate references. CoolProp supplies upstream component constants and liquid correlations.

Before adding data, record component identifiers, units, source and version, usage terms, applicable model, validity limits, and missing parameters. Initial planned components are methane, ethane, propane, nitrogen, carbon dioxide, oxygen, water, and methanol.

`thermo-data` now checks and loads this exact pinned extract and evaluates NASA7 using the reconciled A1 caloric convention. [`components-reacting.provisional.json`](source-extracts/components-reacting.provisional.json) adds hydrogen and carbon monoxide for A17 reactor chemistry. It comes from the same pinned CoolProp and Cantera sources (`validation/prepare-source-data.ps1 -Set reacting`) and is kept separate so that fixtures hashing the base extract stay valid; packages that use these components report the data version `2026-11-07.1+reacting-2026-11-23.1`. It also parses the recorded formulas into element counts and evaluates ideal-gas standard formation enthalpies from the retained a6 constants for the A17 reactors ([reactors](../docs/a17-reactors.md)). The historical filename/schema is retained for source reproduction. Source transcription and permission evidence do not establish experimental accuracy. See [A1–A3 status](../docs/a1-a3-status.md) and [reference qualification](../docs/reference-qualification.md) for formulations, executed comparisons and remaining gates. No fitted binary interactions or implicit numerical defaults are supplied.

#228 adds [`liquid-density-costald.provisional.json`](source-extracts/liquid-density-costald.provisional.json): COSTALD characteristic volumes and SRK acentric factors (Hankinson and Thomson 1979, Table 1) for all ten embedded components, transcribed from the MIT-licensed `chemicals` 1.5.2 redistribution (its [notice](source-extracts/chemicals-LICENSE.txt) is retained) by [`prepare-costald-source-data.py`](../validation/prepare-costald-source-data.py). They feed only the engineering liquid density; see [liquid-density status](../docs/liquid-density-status.md).

A7 adds [`liquid-nrtl.provisional.json`](source-extracts/liquid-nrtl.provisional.json): CoolProp 7.2 vapor-pressure and saturated-liquid density ancillaries for water and methanol, and the ChemSep/DECHEMA 1 atm methanol/water NRTL row (via pinned DWSIM and the MIT-licensed `thermo` redistribution, whose [notice](source-extracts/thermo-LICENSE.txt) is retained). It is produced only by the explicit [`prepare-nrtl-source-data.py`](../validation/prepare-nrtl-source-data.py). Other NRTL pairs and pure-liquid records are deliberately absent and fail as missing data. See [A7 status](../docs/a7-status.md).

#224 adds two ChemSep extension extracts, produced only by [`prepare-chemsep-nrtl-source-data.py`](../validation/prepare-chemsep-nrtl-source-data.py) from the same pinned DWSIM commit (ChemSep 8.3, Artistic License 2.0, [notice](source-extracts/ChemSep-LICENSE.txt) retained). [`components-chemsep.provisional.json`](source-extracts/components-chemsep.provisional.json) holds 1-butanol: ChemSep critical constants, acentric factor and molar mass, and NASA7 coefficients that represent the ChemSep RPP ideal-gas heat-capacity polynomial exactly (a1..a5 = cp/R), with a6/a7 from the ChemSep ideal-gas formation enthalpy and absolute entropy. The polynomial ends at 1000 K, so the upper NASA7 interval is empty and higher temperatures are outside the domain. [`liquid-chemsep-nrtl.provisional.json`](source-extracts/liquid-chemsep-nrtl.provisional.json) holds the ChemSep equation 101 vapour pressure and equation 105 saturated-liquid density of 1-butanol and the ChemSep/DECHEMA 1 atm NRTL rows water/n-butanol and methanol/1-butanol (cross-checked against the `thermo` ChemSep table). Both files are separate so that fixtures hashing the A2/A7 extracts stay valid; selections using 1-butanol report `+chemsep-2026-11-27.1` data versions. 1-butanol has no COSTALD or transport record. See [VLLE status](../docs/vlle-status.md).

#225 adds [`transport.provisional.json`](source-extracts/transport.provisional.json): for the eight base components, the ChemSep 8.3 critical volumes, dipole moments and saturated-liquid viscosity, liquid thermal-conductivity and surface-tension correlations (from the pinned DWSIM copy of the ChemSep database, Artistic License 2.0, [notice](source-extracts/ChemSep-LICENSE.txt) retained), plus the Chung et al. (1988) association factors of water and methanol. It is produced only by [`prepare-transport-source-data.py`](../validation/prepare-transport-source-data.py). Hydrogen and carbon monoxide have no transport record and fail as missing data. See [transport properties](../docs/transport-properties.md).
